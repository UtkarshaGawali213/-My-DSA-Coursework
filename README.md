DSA Coursework in C++

 About the Project

This repository contains C++ implementations of fundamental data structures for Data Structures and Algorithms (DSA) coursework. It demonstrates how stacks and queues can be implemented using arrays and linked lists, along with a music playlist manager based on a doubly linked list.

🎯 Objectives

Understand the working of stacks and queues.

Implement data structures using arrays and linked lists.

Practice insertion, deletion, traversal, and access operations.

Develop logical thinking and problem-solving skills.

Write readable, maintainable, and well-documented C++ code.

 Data Structures and Operations

1. Stack Using Array

Push: Insert an element at the top.

Pop: Remove the top element.

Peek: View the top element.

Display: Show stack elements.

Overflow and underflow conditions should be handled.

2. Stack Using Linked List

Store elements in dynamically allocated nodes.

Perform stack operations following the LIFO principle.

Insert and remove elements at the top of the stack.

3. Queue Using Array

Enqueue: Insert an element at the rear.

Dequeue: Remove an element from the front.

Peek: View the front element.

Display: Show queue elements.

4. Queue Using Linked List

Store elements in dynamically allocated nodes.

Maintain front and rear pointers.

Insert at the rear and remove from the front.

5. Music Playlist Manager

Add and delete songs.

Display songs in forward and reverse order.

Navigate to the current, next, and previous songs.

Play or repeat the playlist.

 Technologies Used

Programming Language: C++

Code Editor: Visual Studio Code

Compiler: GCC (g++)

 How to Compile and Run

Open a terminal in the folder containing the source files.

Compile an individual program using:

g++ Stack_using_array.cpp -o stack_array

Run it on Windows:

.\stack_array.exe

Replace the source filename and output name to compile another program. Each .cpp file contains its own main() function, so compile and run the files separately.

 Learning Outcomes

This coursework provides practice in data structure implementation, pointer manipulation, dynamic memory allocation, algorithmic logic, and code documentation.
